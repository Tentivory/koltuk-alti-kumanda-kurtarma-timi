# Koltuk Altı Kumanda Kurtarma Timi

Bu depo, insanlığın en eski krizini çözmek için kurulmuştur: kumanda koltuk altındadır, televizyon açıktır, kimse kalkmak istememektedir.

Bu bir şaka değildir. Bu bir şakadır. İkisi aynı anda geçerlidir. Tutanak böyledir.

## Misyon

Koltuk minderi ile taban arasında kaybolan uzaktan kumandayı, kırıntı derinliği, bozuk para sayısı, kedi kılı katsayısı ve evdeki umutsuzluk seviyesine göre kurtarmak. Operasyon fiziksel değildir. Matematiktir. Eliniz yine de mindere girecektir. Matematik bunu reddetmez, sadece tutanak tutar.

## Neden var

Çünkü pil bitince herkes ayağa kalkar. Pil bitmeden kimse ayağa kalkmaz. Bu çelişki, modern medeniyetin taşıyıcı kolonudur. Kolon eğilmiştir. Eğim kumandadadır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Minder hariç. Minder depoya sığmadı.

```bash
python kumanda_kurtar.py
```

Argüman da alır, çünkü ciddi kurumlar argüman alır:

```bash
python kumanda_kurtar.py --derinlik 14 --bozuk-para 7 --kirinti 22 --umutsuzluk 0.8 --kedi evet
```

## Çıktı ne işe yarar

Hiçbir işe yaramaz. Ama sayı üretir. Sayı üreten şeyler toplantıda ciddiye alınır. Toplantı yoktur. Yine de ciddiye alınır.

## Operasyon kademeleri

1. Gözle arama. Başarısız olur. Zaten minderin üstünde değildir.
2. El ile arama. Bir çekirdek, iki lira, üç pişmanlık çıkar.
3. Minder kaldırma. Bu noktada komşu duvarın öbür tarafından bakar. Bakmasın.
4. Resmi teslim. Kumanda bulunur ya da bulunmuş sayılır. İkisi de tutanağa geçer.

## Lisans

Kumandayı bulan kullanır. Bulamayan da kullanır, çünkü televizyon zaten açıktı. Sorumluluk mindere aittir.
